### 🔭 What I'm working on

- **[apsimNGpy-soils](https://github.com/Abhi-Plant/apsimNGpy-soils)** — tools for building APSIM-ready soil profiles from **SSURGO** and **SoilGrids**, with pedotransfer functions and APSIM soil-parameter editors.

### 🌿 Background

I come from an agriculture / plant science background and now build software that bridges **field agronomy** and **computational modeling** — crop simulation, soil parameterization, and spatial data pipelines.
